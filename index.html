Aksar puche jane wale sawal (FAQ)

RC download karne me kitna charge lagta hai?

RC Card format ka default rate ₹15 per download hai. MParivahan A4 format jald aa raha hai. Charge sirf tab katta hai jab RC ki front aur back dono images successfully mil jayein.

Kya wallet recharge ke bina RC download ho sakti hai?

Nahi. RC Card download ke liye wallet me kam se kam ek download jitna balance hona chahiye. Recharge WhatsApp support ke through UPI QR se hota hai aur admin verify karke wallet me balance add karta hai.

Download ki hui RC kis format me milti hai?

Ek single PNG image me — RC ka front card upar aur back card neeche, standard card size me. Isse print karna aur share karna dono aasan hota hai.

Kya InstantRCcard ko app ki tarah install kar sakte hain?

Haan. Chrome/Android me "Install InstantRCcard app" button se ya browser menu se install karo. iPhone/iPad par Share → Add to Home Screen use karo. Play Store ki zaroorat nahi hai.

Password bhool gaye to kya karein?

Login page par "Forgot password?" par tap karo, registered email aur mobile number verify karo aur naya password set karo.
