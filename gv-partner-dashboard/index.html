💡 Google Apps Script Deploy Steps (Hindi):

  1. Google Sheet me Extensions > Apps Script kholein.
  2. Tag Mapping > Apps Script Backend Code tab se code copy karein aur wahan paste karein.
  3. Deploy > New deployment par click karein.
  4. Type me Web app chunein.
  5. Who has access: Anyone zaroor karein.
  6. Deploy hone ke baad jo Web App URL mile use yahan paste karke Save karein!
